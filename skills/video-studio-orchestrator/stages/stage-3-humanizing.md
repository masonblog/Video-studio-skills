# Stage 3: Humanizing (Director → Editor)

## 概述
- **输入**：`script-draft.md` + `pipeline-plan.md`
- **输出**：`script-final.md` + 修改报告 (`edit-report.md`)

Editor 的工作是对脚本进行“去 AI 化”润色，使其变成自然、流畅的真人说话口吻。

---

## 核心职责

### 1. 29 条 AI 痕迹扫描
扫描并移除过度强调重要性、宣传腔、谄媚语气、三件套及过度使用的 AI 词汇（如：至关重要、标志着转折点、不可否认等）。完整清单参考本仓库内联的 `humanizer` skill（`skills/humanizer/references/ai-trace-checklist.md`，29 条逐项编号 + 反例 + 改法）。

### 2. 中文专项优化
- **消除翻译腔**：“就...而言”、“在某种程度上”、“值得注意的是”。
- **缩短长句**：拆分为短句，降低听觉理解门槛。
- **避免成语滥用**：少用“众所周知”、“毋庸置疑”等 AI 最爱成语。
- **去掉正式动作词**：“进行测试” → “测试一下”；“开展研究” → “做研究”。

### 3. 朗读测试 (Read-Aloud Test)
润色后必须自己进行模拟朗读，检查句子是否存在绕口、换气点不足或听觉节奏差的问题。

### 4. 🔴 保护 VAS 标记（不可触碰）
脚本中包含的 `[画面:...]`、`[图表:...]`、`[动画:...]`、`[转场:...]`、`[REACT_ANIM_CUE:...]` 标签及其参数是下游 Renderer 的直接动画依据。
- **严禁修改或删除任何视觉标签及其参数**。
- 你的润色范围**仅限于旁白文本**。

---

## 产物格式 (修改报告示例)
```markdown
## 修改报告

### AI 痕迹修复
- [#1 重要性强调] Line 12 "标志着关键的转折点" → 删除（保持客观叙述）
- [#7 高频词] Line 45 "至关重要" → "这里真正需要关注的是..."

### 中文口语化
- Line 23 "进行测试" → "跑一遍测试"

### 朗读调整
- Line 89 原句 28 字过长 → 拆为两句
```
